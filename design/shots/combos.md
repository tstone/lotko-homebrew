# Combos: traffic routes

**Status:** built.

The forest is learning the city's roads. A combo is a 2- or 3-shot route made in a row, and each route pays once per game.

## Today

| Route | Shots |
|---|---|
| Interchange | Dome ramp → lift ramp |
| Return trip | Lift ramp → dome ramp |
| Express line | Lift ramp → arc ramp |
| Roundabout | Right orbit → right orbit |
| Ring road | Right orbit → lift ramp |
| Underpass | Arc ramp → lift ramp |
| Cloverleaf | Dome ramp → lift ramp → dome ramp |
| Grand tour | Dome ramp → right orbit → lift ramp |
| **Gridlock** | Make all 8 routes |

- Each shot after the first must come within about 4 seconds of the one before. Time in a scoop doesn't count.
- A 3-shot route also pays any 2-shot route inside it that the player hasn't made yet.
- The lift ramp only counts with the ramp down.
- Combos run alongside modes and score in multiball too.
